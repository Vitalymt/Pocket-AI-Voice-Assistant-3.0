# Pocket AI Voice Assistant 3.0

**Карманный AI-ассистент. Говори — он ответит.**

Маленький робот из будущего, который помещается в ладони. ESP32-S3, 1.3" OLED-дисплей с живыми глазами, магнитная зарядка, ни одной физической кнопки.

## Что нового в v3.0

По сравнению с [v1](https://github.com/Vitalymt/Pocket-AI-Voice-Assistant) и [v2](https://github.com/Vitalymt/Pocket-AI-Voice-Assistant-2.0):

- 🖥️ **Экран больше** — 1.3" SH1106 OLED (был 0.96" SSD1306). Больше места для глаз и текста
- 🔇 **Ноль физических кнопок** — touch-кнопка спрятана внутри корпуса, реагирует на касание через пластик. Она же кнопка «говорить» и «пробудить из сна»
- 🧲 **Магнитная зарядка** — pogo pins вместо двух разъёмов USB-C. Как в беспроводных наушниках: положил — заряжается
- 📐 **Корпус 43×43 мм** — стал тоньше, отверстий стало меньше (только для динамика)
- 🔊 **Лучший динамик** — чище звук, громче голос ассистента
- 😴 **Умный сон** — экран гаснет через 60 секунд, через 5 минут — глубокий сон. Будится касанием
- 👀 **Живые глаза** — эмоции на экране: нейтральные, радостные, грустные, сонные, слушаю, говорю
- 🌐 **Веб-поиск** — Tavily API, ищет в интернете и отвечает голосом
- 🔄 **OTA-обновления** — прошивка обновляется по воздуху, без проводов

## Характеристики

- **Мозг:** ESP32-S3 N16R8 (16MB flash, 8MB PSRAM)
- **Экран:** SH1106 1.3" OLED, 128×64, I²C
- **Аудио:** I²S, 16kHz, динамик + микрофон
- **Корпус:** 43×43 мм, тонкий, минимум отверстий
- **Кнопка:** емкостная TTP223 внутри корпуса (touch через пластик)
- **Зарядка:** магнитная через pogo pins
- **Аккумулятор:** LiPo
- **Wi-Fi:** 802.11 b/g/n
- **Язык:** русский

## Как работает

1. **Касание** — устройство просыпается, показывает глаза
2. **Говоришь** — глаза становятся «слушающими», микрофон записывает
3. **Думает** — речь уходит в облако, AI обрабатывает
4. **Отвечает** — глаза «говорят», динамик озвучивает ответ
5. **Молчишь 60 секунд** — экран гаснет
6. **Молчишь 5 минут** — глубокий сон, будится касанием

## Компоненты

- **MCU:** ESP32-S3 (XH-S3E-AI V1.0)
- **Дисплей:** SH1106 1.3" OLED (I²C, 128×64)
- **Усилитель:** MAX98357A (I²S)
- **Микрофон:** INMP441 (I²S)
- **Кнопка:** TTP223 (емкостная, внутри корпуса)
- **Аккумулятор:** LiPo
- **Зарядка:** магнитная, pogo pins

## Распиновка

**Дисплей SH1106:**
- VCC → 3.3V
- GND → GND
- SDA → GPIO41
- SCL → GPIO42

**Динамик MAX98357A:**
- DOUT → GPIO7
- BCLK → GPIO15
- LRCK → GPIO16
- VIN → Battery 4.2V

**Микрофон INMP441:**
- SCK → GPIO5
- WS → GPIO4
- DIN → GPIO6
- VCC → 3.3V

**Touch кнопка TTP223:**
- SIG → GPIO43
- VCC → 3.3V

**Светодиод:** GPIO48

## Прошивка

Прошивка основана на [Xiaozhi ESP32](https://github.com/78/xiaozhi-esp32) — open-source платформа для AI-ассистентов.

```bash
# Клонировать репозиторий
git clone https://github.com/Vitalymt/Pocket-AI-Voice-Assistant-3.0.git
cd Pocket-AI-Voice-Assistant-3.0

# Подготовить ESP-IDF
source ~/esp-idf/export.sh

# Собрать
idf.py build

# Прошить через USB
esptool.py --chip esp32s3 -b 460800 write-flash \
    0x0 build/bootloader/bootloader.bin \
    0x8000 build/partition_table/partition-table.bin \
    0xd000 build/ota_data_initial.bin \
    0x20000 build/xiaozhi.bin \
    0x800000 build/generated_assets.bin
```

## Обновления по воздуху (OTA)

Устройство проверяет обновления при каждом включении:

```
Включился → скачивает ota.json → сравнивает версию → если новее → обновляется
```
